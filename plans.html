你的电脑是什么配置？

01

LIGHTWEIGHT

轻量版

把第一句本地回答跑出来。

日常首选
目标设备8GB 内存 · 无独显
模型Qwen2.5 1.5B Instruct
量化Q4_K_M
runtimellama.cpp · CPU
模型大小1.04 GB
上下文4096 tokens

适合

日常问答、摘要、翻译，以及旧电脑和办公本上的第一次本地 AI 体验。

边界

复杂 Agent、长文和高强度代码任务不推荐。这一档的目标是稳定跑通，不是追求最高质量。

02

BALANCED

均衡版

主流办公电脑的通用选择。

主流推荐
目标设备16GB 内存 · 核显或 4GB 独显
模型Qwen2.5 3B Instruct
量化Q4_K_M
runtimellama.cpp · CPU / 轻 GPU
模型大小约 2 GB
上下文4096 tokens

适合

写作、问答、轻量代码和日常办公，比轻量版更自然的中文理解与生成。

边界

不适合高并发长文本任务；4GB 独显只能作为部分加速，不作为硬性要求。

03

PERFORMANCE

性能版

给游戏本和工作站的更强配置。

主流推荐
目标设备16GB 内存 + 8GB 显存
模型Qwen2.5 7B Instruct
量化Q4_K_M
runtimellama.cpp · GPU offload
模型大小约 4.5 GB
上下文4096 tokens

适合

长文、复杂问答、代码生成，以及需要本地模型质量更接近日常生产力的用户。

边界

需要独立 NVIDIA 显卡和合理显存余量。没有独显时不能把这档当成默认方案。

04

ADVANCED · HIGH VRAM

高级版 · Qwen3.8 27B

高显存用户的长文与 Agent 方案。

长文 / Agent
目标设备NVIDIA 12GB+，建议 18–32GB
模型Qwen3.8 27B
量化Q2 / Q3 / Q4 / Q8attn
runtimellama.cpp · CUDA
模型大小9.95–19.13 GB
上下文32K–256K

适合

长文档、复杂 Agent、代码和需要更大模型的用户。按显存自动选择量化档位。

边界

需要 NVIDIA 驱动、CUDA 运行环境和至少约 40GB 可用磁盘；根据显卡选择 Q2、Q4 或 Q8attn 量化版本。

按显存选择量化。 12GB 推荐 Q2_K_XL 短任务配置；18–24GB 推荐 Q4_K_M 长文配置；32GB+ 可选择 Q8attn 和更长上下文。
